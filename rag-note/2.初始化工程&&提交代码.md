# 安装环境
+ 根据`docker-compose-environment.yml`文件安装项目所需环境
> 如果需要的话就是用`docker-compose-environment-aliyun.yml`文件
+ 使用`docker-compose -f docker-compose-envrionment-aliyun.yml up -d`命令创建docker环境。
# 部署模型
+ 使用`docker exec -it ollama /bin/bash`命令或者`Docker Desktop`进入容器。
+ 使用命令下载`deepseek`模型
```shell
# 安装deepseek模型的命令
# 拉取模型
ollama pull deepseek-r1:1.5b
# 运行模型
ollama run deepseek-r1:1.5b
# 拉取向量文本
ollama pull nomic-embed-text
```
